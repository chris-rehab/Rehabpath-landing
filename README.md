RehabPath
A behavioural coaching platform designed to improve patient adherence to physiotherapy rehabilitation programmes.
The core problem: patients stop exercising when pain subsides, long before recovery is complete. RehabPath addresses this behaviour gap through adaptive, personalised messaging that keeps patients engaged through the critical window between clinic visits.
Current status: Early stage. Proof of concept underway in New Zealand. This repository contains the marketing landing page and the native iOS prototype (`ios/` — see `ios/README.md`).
Live prototype: rehabpath-prototype.vercel.app
Built with: HTML, CSS, vanilla JS (site) · SwiftUI (iOS prototype)
